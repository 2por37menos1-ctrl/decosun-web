# Assets de Motorización

Reemplazos visuales pendientes para la landing `/motorizacion`:

- `motorization-hero.webp`: ambiente residencial real con roller motorizada y control remoto.
- `motorization-technician.webp`: técnico DecoSun instalando o configurando una cortina.
- `motor-cutaway.png`: corte técnico validado del conjunto tubo, motor y batería.
- `motor-remote.png`: fotografía oficial del control remoto suministrado.

Hasta contar con material oficial, la página reutiliza fotografías corporativas existentes y una representación conceptual claramente identificada.
